# Application icon

Generated with the built-in imagegen tool, using the owner’s Moyuu turtle-soup mascot as the visual reference. The transparent PNG is packaged into native ICNS sizes by `scripts/make-icon.swift`. The menu bar uses a separate template silhouette in `main.swift`, matching `MenuBarIcon.svg`.

Prompt: Create a macOS NAS helper icon in the reference mascot style: a friendly glossy black cuttlefish with large white eyes embracing a compact ivory two-bay NAS with a tiny teal status light. Soft polished 3D finish, centered compact silhouette, generous safe margin, transparent background, no text or watermark.
